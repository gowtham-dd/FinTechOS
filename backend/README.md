# Quantum FinTech AgentOS — Backend Engine

FastAPI backend application for **Quantum FinTech AgentOS**.

## Features
- LangGraph Multi-Agent Orchestrator with Groq LLM (`llama-3.3-70b-versatile`)
- Elliptic Bitcoin Network Graph Analytics Engine
- Quantum QUBO Optimization Engine (Simulated Annealing vs. Classical ILP)
- Dual Memory Store (Redis with SQLite3 local fallback)

## Usage
```bash
uv run uvicorn app.main:app --reload --port 8000
```
